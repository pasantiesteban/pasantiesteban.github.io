Research

My research lies in the human aspects of software engineering. I use empirical methods to understand how developers, particularly novice developers and student programmers, reason about code, debug software, collaborate, and use development tools.

Programming Cognition

I investigate how developers reason about code while performing software engineering tasks. My work uses both objective (e.g., medical imaging) and self-reported (e.g., surveys) methods to better understand the cognitive processes that shape programming performance, with the goal of informing the design of software engineering tools and instructional strategies that better support programmers.

Indicative papers:

  • Towards a Cognitive Model of Dynamic Debugging: Does Identifier Construction Matter?
  • Causal Relationships and Programming Outcomes: A Transcranial Magnetic Stimulation Experiment.

Programming Interactions

I study how developers interact with one another and with software engineering tools while completing programming tasks. My work examines peer support, communication, and developer-tool interactions to better understand how these interactions influence programming outcomes.

Indicative papers:

  • An Empirical Study of Anonymous, Unmoderated, and Online Peer-to-Peer Programming Tutoring Conversations
  • CirFix: Automated Hardware Repair and Its Real-World Applications

Programming Environments

I investigate the behavioral factors that influence programming outcomes. My work examines how developers' behaviors, as well as the educational and professional environments in which they work, shape programming performance, collaboration, and evaluation.

Indicative papers:

  • Sweat the Details: Exercise Breaks and AI Assistance in Code Summarization.
  • An Analysis of Sex Differences in Computing Teaching Evaluations.
